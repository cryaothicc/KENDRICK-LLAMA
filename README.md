## Overview

Kendrick Llama is a retro-styled web player built around the 2009 self-titled EP. Press play and watch the visualizer react to the beat in real time.

## Features

- Live beat-synced visualizer powered by the Web Audio API
- Full EP playlist
- Retro-inspired interface
- **Bring your own music:** use it as a general-purpose player by adding your own audio files

## Use It as Your Own Player

Click the **Add** button or select a file to load your own tracks. Files are played locally in your browser. Nothing is uploaded or stored in a database, because there is no database.

## Tech Stack

| Layer     | Tools                |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/kendrick-llama.git
cd kendrick-llama

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Then open the local URL printed in your terminal.
