# KENDRICK LLAMA 

https://kendrick-llama.vercel.app/

A retro-styled music player dedicated to Kendrick Lamar self-titled 2009 EP — his first major release before the world knew his name.

Built with React, TanStack Start, Tailwind CSS, and the Web Audio API. Features a live beat-synced visualizer, full playlist.

## 

> Also works as a music player. Just click the Add button or select a file. Nothing will be stored in a database because there is no database.
